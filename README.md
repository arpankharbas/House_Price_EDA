# Ames Housing Exploratory Data Analysis

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Ames Housing Dataset to understand housing characteristics and the factors associated with sale prices.

## Dataset
- Dataset: Ames Housing Dataset
- Rows: 1,460
- Columns: 81
- Target variable: SalePrice

## Objectives
- Understand the dataset structure.
- Analyze numerical and categorical variables.
- Explore missing values.
- Identify outliers.
- Analyze relationships between housing features and sale prices.
- Visualize important patterns.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
- Jupyter Notebook

## Analysis Performed
1. Data Loading and Inspection
2. Missing Value Analysis
3. Descriptive Statistics
4. Univariate Analysis
5. Bivariate Analysis
6. Outlier Detection
7. Correlation Analysis
8. Advanced Visualizations
9. Final EDA Summary

## Key Observations
The analysis explores the relationship between house quality, living area, neighborhood, house style, construction year and sale price.

## Conclusion
EDA was used to identify patterns, distributions, relationships and data-quality issues in the Ames Housing Dataset. This analysis can be used as a foundation for future house price prediction models.
